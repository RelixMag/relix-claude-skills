The Raptive Creator API is currently available to all Insider, Platinum, Platinum Elite, and Luminary sites.

The Raptive Creator API allows you to share your Raptive dashboard data with third-party tools, so you can view and present your data the way you want.

Get started by creating API tokens via the interface in your dashboard. In Account Settings, you’ll find the Raptive Creator API tab:

Give your new token a name and click “Create token.” You will see an inline box that contains your Client ID and Client Secret, both of which you’ll need to connect your third-party tool to the API.

The Client Secret will not be shown again, so be sure to copy it and save it somewhere.

Each user can have up to 16 active API credentials. Credentials expire 365 days after they are created unless they are revoked first.

You can delete any API tokens you create. This will immediately block the token from exchanging or using API access.

Use our public API documentation as a reference to call the Raptive Creator API via third-party tools.

Access to the Raptive Creator API is linked to your Raptive dashboard user and permissions. This means that any user can create API tokens, and each user will be able to access the sites and data via the API that they currently have access to via their dashboard.

Our API can be used in a number of useful ways, like the common use cases mentioned at the top of this article. Many creators and publishers want to view their Raptive performance alongside other business data, and many choose to create custom dashboards that allow them to organize their data in a way that best supports their workflows.
